# assets/ — фотографии товаров

Реальные фотографии товаров хранятся в `assets/products/` (добавлены 29.10.2026
из подтверждённого источника aifirsts.github.io/s/catalog — 12 файлов на 13
позиций; `image-the-max-supply.jpg` и `image-md-power-c-and-biotech-supply.jpg`
используются двумя карточками каждая). Если у товара массив `photos` пуст —
показывается заглушка с названием бренда; заглушки не имитируют товар.

## Как добавить фото

1. Положите файл в `assets/`, например `assets/bs-001.jpg`.
2. Откройте `data/products.json` и добавьте путь в массив `photos` нужного товара:

```json
"photos": ["assets/bs-001.jpg"]
```

Сайт автоматически покажет первое фото из массива в карточке товара.
Если массив `photos` пуст — показывается заглушка.

## Правила

- Фото должно соответствовать реальному товару (фото с Avito-объявления продавца).
- Не использовать стоковые и сгенерированные изображения вместо фото реального товара.
- Оптимизируйте вес: до ~200 КБ на файл, WebP или JPEG.
- Указывайте размеры (ширина/высота) при необходимости — фото выводится с `loading="lazy"`.
