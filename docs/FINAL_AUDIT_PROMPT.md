# ФИНАЛЬНЫЙ ПРОМПТ: профессиональный полный аудит и апгрейд сайта Beauty Supply (v3.0)

> Исполняемый промпт. Создан 29.10.2026 по указанию владельца. Приоритет новых указаний владельца выше прежнего позиционирования и прежней схемы каталога.

## Роль и задача

Ты — senior frontend-инженер и QA-специалист. Проведи финальный полный аудит действующего статического сайта-каталога Beauty Supply и выполни апгрейд по приведённым ниже требованиям. Работай по циклу: аудит → изменение → проверка → отчёт.

## Контекст

- Сайт: статический каталог, чистые HTML/CSS/JS, без библиотек, без внешних CDN; каталог в `data/products.json` читается через `fetch` (сайт работает только по HTTP).
- Заказы только через Telegram (`TELEGRAM_URL` в начале `app.js`), без корзины, оплаты, бэкенда, личного кабинета.
- Приватный репозиторий GitHub `usaforyou/beauty-supply`; превью Perplexity Computer; опубликованный адрес `https://beautysupplyru.pplx.app`.
- Источник данных (новый, утверждённый владельцем): `https://aifirsts.github.io/s/catalog/` — фото, описания, цены, статусы.

## Новые указания владельца (высший приоритет)

1. **Позиционирование — Россия, а не Москва. Доставка по всей России.** Заменить упоминания Москвы в позиционировании: `<title>`, meta description, OG, hero (eyebrow, H1, подзаголовок), преимущества, заголовки секций каталога, FAQ, футер. НЕ трогать фактические адреса источников (Avito-ссылки) и не выдумывать перевозчиков, стоимости, сроки и условия доставки — только факт «доставляем по всей России, условия согласовываются с оператором».
2. **Фото, описания, цены — из источника** `https://aifirsts.github.io/s/catalog/`. Скачай фото локально в `assets/products/`, привяжи пути в `products.json`. Описания возьми дословно из источника. Не выдумывай характеристики.
3. **Статусы — по источнику:** все 13 позиций «в наличии» (подтверждено 29.10.2026); 3 новые позиции — «Новое поступление» (в наличии, не предзаказ). Схема секций: «Товары в наличии» (10) + «Новое поступление» (3).

## Аудит (обязательные проверки)

1. **Контент и данные**: JSON валиден; 13 товаров; цены сверены с источником построчно; описания совпадают с источником; нет запрещённых фраз («100% оригинал», «гарантия», «беспошлинный ввоз», «гарантированная доставка», «лучшая цена», «возврат без условий»); нет упоминаний старого позиционирования в пользовательских текстах.
2. **Изображения**: все фото загружаются (HTTP 200), валидные JPEG, локальные пути, осмысленный alt, нет искажений; заглушки удалены.
3. **Адаптив**: 320/375/768/1280 — нет горизонтального overflow, нет переносов внутри пунктов меню, сетки корректны, текст не обрезан.
4. **Доступность**: контраст, aria-атрибуты, клавиатурная навигация (FAQ через Tab/Enter), alt у фото.
5. **Производительность**: `loading="lazy"` у фото, `decoding="async"`, разумный вес страницы.
6. **SEO**: title/meta/OG отражают Россию и доставку; один H1; корректная структура заголовков.
7. **Безопасность**: XSS закрыт `escapeHtml`; `target="_blank"` с `rel="noopener noreferrer"`; секретов нет; служебные файлы (`.git`, `docs/`) не публикуются.
8. **Поток заказа**: все 13 автотекстов Telegram сверены с JSON; статические ссылки ведут на TELEGRAM_URL; фильтрация hidden/sold; состояние ошибки при битом JSON.

## Запрещено

- Выдумывать характеристики товаров, условия доставки, сроки, цены.
- Возвращать исключённые брифом товары (MoonSwatch, чехлы Speck, палетка Hourglass за 6000 ₽).
- Нарушать технические ограничения (никаких библиотек, CDN, корзины, оплаты, бэкенда).
- Переписывать Git-историю и публиковать сайт без явного подтверждения владельца.

## Формат отчёта

Отчёт аудита: таблица «проблема → исправление → доказательство (проверка/скриншот) → остаточное ограничение». Каждая проверка — с фактическим результатом (число, статус, скриншот), не «пройдено» на глаз. Изменения в Git — обычным коммитом апгрейда. После апгрейда: полное регрессионное тестирование по FLOWS, деплой превью, обновление базы знаний Project, запрос у владельца подтверждения на перепубликацию.

## Критерии приёмки

- Все 8 блоков аудита закрыты с доказательствами.
- Позиционирование: Россия и доставка по всей России во всех пользовательских текстах; Москва не упоминается в позиционировании (кроме фактических адресов источников).
- 13 карточек с реальными фото, описаниями и ценами из источника; 10 в наличии + 3 «Новое поступление».
- Регрессия FLOWS пройдена полностью; живое превью проверено в свежем браузерном контексте.
