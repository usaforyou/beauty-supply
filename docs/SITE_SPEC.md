# SITE_SPEC.md — спецификация сайта Beauty Supply

Версия: 1.0 · Дата: 2026-10-29 · Статус: реализовано

## 1. Что это

Статический сайт-каталог Beauty Supply: косметика и уход из США, часть товаров в Москве.
Заказ оформляется через Telegram. Нет корзины, онлайн-оплаты, личного кабинета и backend.

## 2. Структура проекта

```
beauty-supply/
├─ index.html          — единственная страница сайта
├─ styles.css          — все стили (mobile-first, от 320 px)
├─ app.js               — логика: загрузка и отрисовка каталога
├─ data/products.json  — каталог товаров (единственный источник данных)
├─ assets/README.md     — правила добавления фотографий
├─ docs/SITE_SPEC.md   — этот файл
├─ docs/PROMPT_AUDIT.md — аудит исходного промпта-брифа
└─ docs/IMPROVED_PROMPT.md — улучшенный промпт
```

## 3. Настройка Telegram

В начале `app.js` есть константа:

```js
const TELEGRAM_URL = 'https://t.me/beautysupply_ru';
```

Это единственная точка настройки. При смене оператора или канала измените
только эту строку. Все кнопки обновляются из неё:

- статические ссылки (шапка, hero, footer) помечены атрибутом `data-telegram`
  и получают `href` из константы при загрузке страницы (href в HTML — запасной
  вариант на случай отключённого JS);
- кнопки в карточках товаров генерируются при отрисовке каталога и содержат
  автотекст «Здравствуйте! Хочу заказать товар BS-XXX — Название.».

В `data/products.json` дублирующая настройка `telegram_url` намеренно
отсутствует — источник один.

## 4. JSON-схема товара

```json
{
  "id": "BS-001",
  "title": "Название товара",
  "brand": "Бренд",
  "category": "Косметика | Уход за кожей | Уход за телом",
  "price_rub": 0,
  "status": "in_stock | preorder | hidden | sold",
  "city": "Москва",
  "short_description": "Краткое описание",
  "photos": [],
  "source": "Avito | MATRIX2",
  "source_url": "",
  "stock": null,
  "preorder_note": "",
  "price_note": "",
  "updated_at": "2026-10-29"
}
```

Изменения против схемы брифа (см. docs/PROMPT_AUDIT.md, пункт 9):

- `stock` может быть `null` — «наличие подтверждено, точный остаток неизвестен».
  Бриф использовал `stock: 1` без подтверждения остатка.
- добавлен необязательный `price_note` — примечание о происхождении цены
  (используется для BS-006 и BS-009, обновлённых по переписке от 28.10.2026).

## 5. Правила обновления каталога

1. Все изменения товаров — только в `data/products.json`. Разметку менять не нужно.
2. Товар с `status: "hidden"` или `"sold"` не отображается (но остаётся в JSON для истории).
3. Цена неизвестна → не публикуйте товар с ценой 0: поставьте `status: "hidden"`
   и уточните цену у оператора. Цена 0 ₽ в витрине запрещена.
4. Новое поступление: присвойте следующий свободный `BS-XXX`, заполните все поля,
   `source_url` — ссылка на источник (Avito-объявление или MATRIX2).
5. У товара продана последняя единица → `status: "sold"`.
6. Смена цены: обновите `price_rub`, поставьте актуальную дату в `updated_at`,
   при необходимости добавьте `price_note` (откуда новая цена).
7. После правок проверьте валидность JSON и откройте сайт — счётчики секций
   должны сойтись с числом товаров соответствующего статуса.

## 6. Решения по данным (зафиксировано)

### 6.1 Дубли из блока 28.10.2026

Блок «пополнение склада от 28.10.2026» на MATRIX2 содержит 5 позиций, из них 2
дублируют товары в наличии с обновлёнными ценами продавца:

| Позиция из блока 28.10 | Решение |
|---|---|
| Daily Prevention SPF 30 (4 900 ₽) | BS-006: цена обновлена 5 900 → 4 900 ₽, дублирующая карточка предзаказа не создавалась |
| IMAGE MD Biotech Longevity Crème (10 400 ₽) | BS-009: цена обновлена 12 999 → 10 400 ₽, дублирующая карточка предзаказа не создавалась |
| IMAGE The MAX Crème (11 500 ₽) | BS-011, предзаказ |
| IMAGE The MAX Eye Crème (6 800 ₽) | BS-012, предзаказ |
| IMAGE MD Restoring Power-C Serum (11 500 ₽) | BS-013, предзаказ |

Итог: 10 в наличии + 3 предзаказа = 13 товаров. Слот BS-015 из брифа не
использовался: показывать посетителю 5 карточек предзаказа при подтверждённых
данных только для 3 значило бы дублировать товары или выдумывать данные.

### 6.2 Заполненные пробелы брифа (из MATRIX2 — разрешённый источник)

- BS-007 (ночной крем с витамином C) — бренд IMAGE Skincare, линия Vital C.
- BS-008 (смарт-крем SPF 75) — бренд IMAGE Skincare.
- BS-004/BS-005 — бренд IMAGE Skincare (линия VOL.U.LIFT), в брифе бренд был
  указан как «VOL.U.lift».
- BS-005 (концентрат VOL.U.LIFT) — категория «Уход за телом» (MATRIX2 относит
  обе позиции VOL.U.LIFT к уходу за телом; бриф указывал «Уход за кожей»).

Источники: [MATRIX2, каталог](https://aifirsts.github.io/MATRIX2/index.html#catalogue),
[демо-сайт продавца](https://aifirsts.github.io/s/).

### 6.3 Происхождение обновлённых цен BS-006 и BS-009

Цены от 28.10.2026 взяты из блока «цены из переписки с продавцом» на
[MATRIX2](https://aifirsts.github.io/MATRIX2/index.html#catalogue); `source_url`
этих товаров по-прежнему указывает на архивное объявление Avito (происхождение
позиции), а актуальная цена и её источник зафиксированы в `price_note`.

### 6.4 Статус предзаказа

Позиции BS-011–BS-013 — новые предложения продавца из блока пополнения
от 28.10.2026, отсутствующие в архиве Avito-объявлений. Статус `preorder`
установлен по согласованной владельцем схеме каталога (10 + 3); их появление
в витрине демо-сайта как «в наличии» относится к демо и здесь не учитывалось.
Схема каталога «10 + 3 = 13» (без дублирования товаров между секциями)
утверждена владельцем 29.10.2026.

### 6.5 Excluded-товары

Часы MoonSwatch, чехлы Speck и палетка Hourglass за 6 000 ₽ в каталог не включены
(см. раздел 5 брифа). Charlotte Tilbury Pillow Talk за 6 000 ₽ осталась — исключалась
именно палетка Hourglass, а не любая позиция за эту сумму.

## 7. Технические ограничения (по брифу)

- Только HTML/CSS/JS, без React, Vue, Tailwind, Bootstrap, jQuery и внешних CDN.
- Шрифты — системные стеки (бриф запрещает внешние запросы; компромисс зафиксирован
  в аудите, пункт 11).
- Каталог читается через `fetch('data/products.json')`.
- Фильтрация: `in_stock` → секция «В наличии», `preorder` → «Предзаказ»,
  `hidden`/`sold` не отображаются.
- Mobile-first, адаптив от 320 px.
- Никаких платежных систем и backend.
- GitHub Pages не используется как боевой хостинг (по брифу).

## 8. Проверка сайта локально

Открытие `index.html` двойным щелчком (file://) не работает корректно из-за
`fetch` — это ограничение браузеров, а не сайта. Локальная проверка:

```bash
cd beauty-supply
python3 -m http.server 8000
# открыть http://localhost:8000
```

## 9. Приёмка (фактические значения)

1. Сайт открывается по HTTP (локально и на превью-хостинге).
2. `data/products.json` загружается через fetch.
3. В разделе «В наличии» отображается 10 товаров.
4. В разделе «Предзаказ» отображается 3 товара (см. п. 6.1 — решение по дублям).
5. Часов и чехлов нет.
6. Палетки Hourglass за 6 000 ₽ нет.
7. Кнопки Telegram ведут на https://t.me/beautysupply_ru с автотекстом заказа.
8. Сайт адаптивен от 320 px (проверено на 320/375/768/1280).
9. Корзины, оплаты и backend нет.
10. Запрещённых формулировок нет («100% оригинал», «гарантия» и др.).
11. Дисклеймер в footer присутствует.
12. Один финальный commit в репозитории.

## 10. Обновление 29.10.2026 (вторая редакция)

Указания владельца (приоритет над прежней схемой):

   пользовательских текстах (title, meta, OG, hero, преимущества, заголовки

   только «условия согласовываются с оператором».
2. **Новый источник данных:** [aifirsts.github.io/s/catalog](https://aifirsts.github.io/s/catalog/)
   — фото (`assets/products/`, 12 файлов), описания (дословно), цены (совпали
   с текущими), статусы. Все цены снабжены `price_note` «Цена подтверждена
   29.10.2026».
3. **Статусы по источнику:** все 13 позиций «в наличии». Схема секций:
   «Товары в наличии» (10) + «Новое поступление» (3, поле `is_new: true`,
   бейдж «Новое поступление», статус `in_stock`). Прежний предзаказ (BS-011–
   BS-013) упразднён — источник подтверждает их наличие. Легаси-фолбэк
   `status: preorder` в app.js сохранён.
4. **BS-005** (VOL.U.LIFT Concentrate) — категория «Уход за кожей» (по
   источнику: «Кремы для лица»); прежде была «Уход за телом».
5. **Alt-тексты фото** — из источника (поле `photo_alt`).
6. Ассеты версионируются `?v=5`. Апгрейд закоммичен отдельным коммитом
   `feat: Russia-wide positioning, real photos, new arrivals section` —
   поверх единого финального коммита первой редакции (история не
   переписывалась).
